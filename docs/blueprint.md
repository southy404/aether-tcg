# **App Name**: Core-Rift Nexus

## Core Features:

- Card Collection: Display the user's card collection, sortable by type, rarity, and cost.
- Shop: Allow players to purchase card packs with in-game currency.
- Pack Opening: Simulate the opening of a card pack, revealing cards one by one.
- Card Database: Maintain a database of available cards with stats and descriptions.
- AI Deck Advisor: Suggest improvements to the player's deck, based on the current meta. LLM will use a tool to determine meta information.
- Currency System: Track player's in-game currencies (Gems and Gold).
- Animated Card Details: Implement a smooth, interactive card detail view on hover using animations to enhance user engagement.

## Style Guidelines:

- Primary color: Gold (#D4AF37) for highlighting key elements.
- Background color: Dark grey (#050505) to provide a contrast and focus on the cards.
- Accent color: Blue (#3498DB) for interactive elements and mana representation.
- Font: 'Segoe UI' (sans-serif) for a clean, modern look throughout the app.
- Use custom icons for card stats (attack, health) and resource types (mana, energy).
- Employ a grid-based layout for the card collection and shop views to ensure responsive design.
- Incorporate smooth transitions and card flipping animations during pack openings.
